## 🌐 About the Project

This project is a **student portfolio website** created to introduce Riya, showcase her skills, highlight her projects, and provide contact information.

The website contains four main sections:

- 🧑‍💻 About Me
- 🛠️ Skills
- 📂 Projects
- 📩 Contact

The HTML file provides the structure and content of the website, while CSS is used for styling and visual appearance.

---

## 🎯 Features

- 🧑‍💻 Personal **About Me** section
- 🛠️ **Skills** section
- 📂 **Projects** section
- 📩 **Contact** section
- 🧭 Navigation menu
- 🎨 Simple blue-and-white design
